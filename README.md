## This repository contains scripts for microbiome data analysis used in the work: "Functional Reprogramming of the Gut Microbiome by Enteral Nutrition After Acute Colonic Injury in Rats"

**Jul 2026**

### Software
Analysis was performed on Ubuntu 24.04.1 LTS using the following software:

```
Python v3.10.4
Fastp v0.23.4
hostile v2.0.2
bowtie2 v2.5.2
BBTools (v jul 2026)
kraken2 v2.17.1
HUMAnN v4.0.0.alpha.2
NCBI dataset utility v18.33.1
MMseqs2 v18.8cc5c
DIAMOND aligner v2.1.9
```
### Databases
```
kraken2 Standard-16 database (dated 6/26/2026, with default minimizer size of 31)
HUMAnN v4.0.0.alpha.2 EC-filtered UniRef90 (HUMAnN v4/v2019_06 accessed 8 july 2026)
```
